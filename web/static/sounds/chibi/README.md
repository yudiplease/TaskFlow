# Звуки чиби-персонажа (Ася)

Короткие вокальные звуки вместо озвучки диктора. Файлы подкладывает
человек: положи сюда свои MP3 с такими же именами — код подхватит их
автоматически при следующей загрузке страницы.

| Файл | Категория | Реакция |
|---|---|---|
| `nya-01.mp3`, `nya-02.mp3` | `nya` — «няя» | ошибка, появление Аси |
| `giggle-01.mp3`, `giggle-02.mp3` | `giggle` — «хи-хи» | клик по персонажу |
| `hum-01.mp3` | `hum` — «угу» | успешное действие, бездействие |
| `squee-01.mp3` | `squee` — восторг | зарезервировано (празднования) |

Текущие `*.mp3` — **тихие заглушки** (валидный MP3 из кадров тишины):
приложение работает без ошибок, пока реальные файлы не добавлены.

Требования к файлам:

- формат MP3 (OGG-fallback не нужен);
- длительность меньше 2 секунд;
- имена менять нельзя — по ним строится пул в `chibi-sounds.js`
  (константа `SOUND_FILES`). Добавить вариант — добавить файл
  `nya-03.mp3` и путь в `SOUND_FILES`.
